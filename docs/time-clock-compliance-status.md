# Status Regulatorio do Ponto

O sistema possui recursos tecnicos de ponto: NSR, hash, comprovante, auditoria, GPS, QR, dispositivo e previews de arquivos.

Isto nao equivale a REP-P homologado. Arquivos AFD/AEJ/espelho permanecem como previas tecnicas ate validacao formal de layout, assinatura, certificados, enquadramento juridico e homologacao externa.

`FEATURE_OFFICIAL_PAYROLL=false` deve permanecer ativo. O modulo e pre-folha para conferencia, estimativa e memoria de calculo.
