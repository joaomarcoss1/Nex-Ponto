# Privacidade e LGPD — base técnica

Categorias: identificação, vínculo trabalhista, jornada, localização, documentos, finanças, autenticação e auditoria.

Controles técnicos: tenant, filial, permissões granulares, mascaramento público, storage privado, URL assinada, hash de IP/anexos, sanitização de logs, trilha de acesso e retenção documentável.

Campos organizacionais a preencher antes do piloto:

- controlador/operador;
- finalidade e base legal;
- retenção por categoria;
- subprocessadores;
- aviso de geolocalização;
- canal do titular;
- procedimento de exportação, correção, anonimização e incidente.

Esta documentação não declara conformidade jurídica automática.
